# Sims Game

A browser-based life simulation game inspired by The Sims. Build rooms, manage characters, and explore — all in your browser.

![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)
![CSS](https://img.shields.io/badge/CSS-1572B6?logo=css3&logoColor=white)

## Play

**[Launch Sims Game](https://kashmot2.github.io/sims-game/)**

## Features

- Sims-style gameplay in the browser
- Character and room management
- Ambient audio
- Responsive CSS layout

## Run Locally

```bash
git clone https://github.com/kashmot2/sims-game.git
cd sims-game
python3 -m http.server 8000
# open http://localhost:8000
```
